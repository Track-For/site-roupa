# Alderwyck & Vale

A cinematic, fictional fashion-house MVP built with Vue 3, Vite, JavaScript, GSAP and ScrollTrigger.

## Run locally

```bash
npm install
npm run dev
```

Production and interaction checks:

```bash
npm run build
npm test
```

## Included experiences

- 1.6-second opening vignette with book-cover reveal
- Sticky navigation, mobile menu and working wardrobe drawer
- Full-viewport campaign hero
- Pinned Estate Journey through Library, Garden and Club Room
- Pinned marble-pedestal blazer study
- Interactive material library and collection index
- Cinematic sticky lookbook
- Private fitting modal with completion state
- Fictional heritage timeline
- Six-piece product collection with quick view, colour, size and add-to-wardrobe flow
- Interactive dress codes and wardrobe builder
- Journal, final estate CTA and correspondence form
- Mobile-specific natural-flow fallbacks and reduced-motion support

All brand names, history, people, products, prices, addresses and imagery are fictional. Generated visual references are stored in `design-references/`; production imagery is stored under `src/assets/`.
